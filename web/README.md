# 🏥 医疗 Agent Web 测试面板

基于 Streamlit 实现的交互式 Web 测试界面

## 🚀 快速启动

```bash
# 方法 1：使用启动脚本（推荐）
python web/run_app.py

# 方法 2：直接使用 Streamlit 命令
streamlit run web/app.py --server.port 8501
```

## 🌐 访问地址

启动成功后访问：**http://localhost:8501**

## ✨ 功能特性

### 💬 实时聊天界面
- 直观的对话交互
- 消息历史记录
- 流式响应显示

### 🎯 意图识别展示
- 自动识别问题意图
- 显示置信度分数
- 支持 4 种意图类型

### 📚 RAG 检索结果
- 医疗问题自动显示检索文档
- 相似度分数可视化
- 可展开查看详情

### 📊 系统状态监控
- API 连接状态
- LLM 状态
- RAG 知识库状态
- 意图识别状态

## 📖 使用说明

### 1. 输入问题
在底部输入框输入您的问题

### 2. 查看意图
系统自动识别问题意图并显示

### 3. 获取回答
AI 生成专业回答

### 4. 查看检索
医疗问题会显示 RAG 检索结果

## 🔧 技术栈

- **前端框架**：Streamlit 1.55.0
- **后端**：Python 3.10+
- **LLM**：智谱 AI GLM-4-Flash
- **向量库**：FAISS
- **Embedding**：智谱 AI Embedding-2

## ⚙️ 配置说明

### 环境变量（.env.dev）

```bash
# API 配置
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_MODEL=glm-4-flash

# Web 配置
WEB_PORT=8501
WEB_THEME=light
```

## 🐛 常见问题

### 端口被占用
```bash
# 更换端口
streamlit run web/app.py --server.port 8502
```

### API Key 错误
检查 `.env.dev` 中的 `LLM_API_KEY` 配置

### RAG 检索不工作
运行以下命令构建向量库：
```bash
python scripts/build_knowledge_base.py
```
