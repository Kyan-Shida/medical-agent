# 路径问题修复指南

## ❌ 问题描述

在运行测试文件时遇到 `ModuleNotFoundError`：

```
ModuleNotFoundError: No module named 'config'
```

## 🔍 原因分析

测试文件分布在不同的目录层级，需要使用正确的相对路径才能找到项目根目录。

### 目录结构

```
medical/                    # 项目根目录
├── config/                 # 配置模块
├── core/                   # 核心模块
├── utils/                  # 工具模块
│
└── tests/                  # 测试目录
    ├── test_config.py      # ❌ 路径错误
    │
    └── rag/                # RAG 测试子目录
        └── test_rag_simple.py  # ❌ 路径错误
```

### 路径计算规则

从测试文件到项目根目录的层数：

| 文件位置 | 路径 | parent 次数 |
|---------|------|-----------|
| `tests/test_config.py` | tests/ → medical/ | **2 次** |
| `tests/rag/test_rag_simple.py` | tests/rag/ → tests/ → medical/ | **3 次** |

## ✅ 修复方案

### 1. 修复 `tests/test_config.py`

**错误代码**：
```python
project_root = Path(__file__).parent.parent.parent  # ❌ 3 次，太多了
```

**正确代码**：
```python
project_root = Path(__file__).parent.parent  # ✅ 2 次，正确
# tests/ -> medical/
```

### 2. 修复 `tests/rag/test_rag_simple.py`

**错误代码**：
```python
project_root = Path(__file__).parent.parent  # ❌ 2 次，不够
```

**正确代码**：
```python
project_root = Path(__file__).parent.parent.parent  # ✅ 3 次，正确
# tests/rag/ -> tests/ -> medical/
```

## 📝 路径规则总结

### 通用公式

```python
# 添加项目根目录到路径
project_root = Path(__file__).parent  # 当前目录
project_root = Path(__file__).parent.parent  # 父目录
project_root = Path(__file__).parent.parent.parent  # 祖父目录
# ...
```

### 判断方法

数一下从测试文件到项目根目录需要经过多少层目录：

```
tests/test_config.py
  ↓ (1 层 parent)
tests/
  ↓ (2 层 parent)
medical/  ✅ 到达根目录

需要 2 层 parent
```

```
tests/rag/test_rag_simple.py
  ↓ (1 层 parent)
tests/rag/
  ↓ (2 层 parent)
tests/
  ↓ (3 层 parent)
medical/  ✅ 到达根目录

需要 3 层 parent
```

## 💡 避免路径问题的最佳实践

### 1. 使用 pytest 运行

```bash
# ✅ 推荐：pytest 会自动处理路径
python -m pytest tests/ -v

# ❌ 不推荐：直接运行可能需要手动设置路径
python tests/test_config.py
```

### 2. 使用 conftest.py

在 `tests/` 目录创建 `conftest.py`：

```python
# tests/conftest.py
import sys
from pathlib import Path

# 自动添加项目根目录到路径
project_root = Path(__file__).parent.parent
sys.path.insert(0, str(project_root))
```

### 3. 使用相对导入（如果在包内）

```python
# ✅ 如果在包内部
from ..config.base_config import BaseConfig

# ❌ 绝对导入（需要正确设置路径）
from config.base_config import BaseConfig
```

## ⚠️ 常见错误

### 错误 1：parent 层数错误

```python
# ❌ 错误：层数太多
project_root = Path(__file__).parent.parent.parent  # 对于 tests/test_config.py

# ✅ 正确
project_root = Path(__file__).parent.parent
```

### 错误 2：忘记添加 sys.path

```python
# ❌ 错误：只计算路径，没添加
project_root = Path(__file__).parent.parent

# ✅ 正确：计算并添加
project_root = Path(__file__).parent.parent
sys.path.insert(0, str(project_root))
```

### 错误 3：使用绝对路径

```python
# ❌ 错误：硬编码绝对路径
sys.path.insert(0, 'D:\\traeFile\\agent\\medical')

# ✅ 正确：使用相对路径
project_root = Path(__file__).parent.parent
sys.path.insert(0, str(project_root))
```
