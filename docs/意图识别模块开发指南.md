# 意图识别模块开发指南

## 🎯 模块概述

意图识别模块是医疗 Agent 的"大脑"，负责理解用户意图并路由到正确的处理分支。

## 核心功能

### 1. 意图分类

**支持的意图类型**：

| 意图 | 说明 | 示例 |
|------|------|------|
| **medical** | 医疗问题 | "孩子发烧了怎么办？" |
| **chat** | 闲聊 | "你好"、"谢谢" |
| **unanswerable** | 无法回答 | "如何制造毒药？" |
| **health_plan** | 健康计划 | "帮我制定减肥计划" |

### 2. 子分类

**仅用于医疗问题**：

| 子分类 | 说明 | 示例 |
|--------|------|------|
| **pediatrics** | 儿科 | 儿童、婴儿、幼儿相关 |
| **general** | 其他 | 成人或其他科室 |

### 3. 路由分发

根据分类结果自动路由到对应的处理器。

## 核心组件

### 1. IntentClassifier - 意图分类器

**位置**: [`core/intent/classifier.py`](file://d:\traeFile\agent\medical\core\intent\classifier.py)

**功能**：
- ✅ LLM + 规则混合分类
- ✅ 置信度评估
- ✅ 子分类识别
- ✅ 批量分类

**使用示例**：

```python
from config.base_config import BaseConfig
from config.llm_config import LLMConfig
from core.llm.client import LLMClient
from core.intent.classifier import IntentClassifier

# 初始化
config = BaseConfig(env_file=".env.dev")
llm_config = LLMConfig.from_env(config)
llm_client = LLMClient(llm_config)
classifier = IntentClassifier(llm_client)

# 分类
result = classifier.classify("孩子发烧了怎么办？")

print(f"意图：{result['intent']}")        # IntentType.MEDICAL
print(f"置信度：{result['confidence']}")  # 0.98
print(f"子分类：{result['sub_category']}") # SubCategory.PEDIATRICS
print(f"理由：{result['reason']}")        # "询问儿童发烧处理方法"
```

**分类流程**：

```
用户输入
  ↓
规则预过滤（快速匹配）
  ↓
LLM 分类（深度理解）
  ↓
结果验证（格式校验）
  ↓
返回分类结果
```

### 2. IntentRouter - 意图路由器

**位置**: [`core/intent/router.py`](file://d:\traeFile\agent\medical\core\intent\router.py)

**功能**：
- ✅ 自动路由到处理器
- ✅ 支持自定义处理器
- ✅ 降级处理
- ✅ 置信度阈值控制

**使用示例**：

```python
from core.intent.router import IntentRouter

# 初始化
router = IntentRouter(classifier)

# 路由
result = router.route("孩子发烧了怎么办？")

print(f"成功：{result['success']}")
print(f"意图：{result['intent']}")
print(f"消息：{result['message']}")
```

**路由流程**：

```
用户输入
  ↓
意图分类
  ↓
置信度检查
  ↓
获取处理器
  ↓
执行处理
  ↓
返回结果
```

## 完整使用示例

### 示例 1：简单分类

```python
from core.intent.classifier import IntentClassifier, IntentType

# 分类
result = classifier.classify("你好")

if result["intent"] == IntentType.CHAT:
    print("这是闲聊")
elif result["intent"] == IntentType.MEDICAL:
    print(f"这是医疗问题 - {result['sub_category'].value}")
```

### 示例 2：路由处理

```python
from core.intent.router import IntentRouter

# 路由
result = router.route("3 岁孩子发烧 39 度怎么办？")

if result["success"]:
    if result["intent"] == IntentType.MEDICAL:
        print(f"医疗问题：{result['sub_category']}")
        # 调用 RAG 检索 + LLM 生成
    elif result["intent"] == IntentType.CHAT:
        print(f"闲聊：{result['message']}")
    elif result["intent"] == IntentType.UNANSWERABLE:
        print(f"无法回答：{result['message']}")
    elif result["intent"] == IntentType.HEALTH_PLAN:
        print(f"健康计划：{result['message']}")
else:
    print(f"处理失败：{result['message']}")
```

### 示例 3：自定义处理器

```python
from core.intent.router import IntentRouter
from core.intent.classifier import IntentType

# 注册自定义处理器
@router.register(IntentType.MEDICAL)
def custom_medical_handler(query, context):
    """自定义医疗问题处理器"""
    # 1. RAG 检索
    # 2. LLM 生成回答
    # 3. 返回结果
    
    return {
        "success": True,
        "intent": IntentType.MEDICAL,
        "message": "自定义处理逻辑",
        "answer": "生成的回答",
    }

# 路由会自动使用自定义处理器
result = router.route("发烧怎么办？")
```

### 示例 4：批量分类

```python
texts = [

```

**A**:
```python

    query,
```
