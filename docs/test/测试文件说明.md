## ⚠️ 常见问题

### 问题 1：ModuleNotFoundError

```
ModuleNotFoundError: No module named 'config'
```

**解决**：
```bash
# 确保从项目根目录运行
cd d:\traeFile\agent\medical
python -m pytest tests/ -v
```

### 问题 2：测试失败（配置相关）

```
AssertionError: assert '9f2e028d14f7...' == 'test_api_key'
```

**原因**：测试使用了真实的 API Key（从 `.env.dev` 读取）

**解决**：这是正常现象，不影响实际功能。可以忽略或修改测试期望值。

### 问题 3：API Key 无效

```
LLMCallError: API Key 无效
```

**解决**：
1. 检查 `.env.dev` 中的 `LLM_API_KEY` 是否正确
2. 确认 API Key 在智谱 AI 平台有效
3. 确保没有多余空格

### 问题 4：Redis 连接失败

```
redis.exceptions.ConnectionError
```

**解决**：
```bash
# 启动 Redis
docker run -d -p 6379:6379 redis:alpine

# 或者跳过需要 Redis 的测试
python -m pytest tests/ -v -k "not cache"
```

## 🎓 编写测试的最佳实践

### 1. 测试文件命名

```python
# ✅ 正确：test_<module>.py
test_llm_client.py
test_rag.py

# ❌ 错误
llm_test.py
test.py
```

### 2. 测试类命名

```python
# ✅ 正确：Test<Module>
class TestLLMClient:
    ...

# ❌ 错误
class LLMClientTest:
    ...
```

### 3. 测试方法命名

```python
# ✅ 正确：test_<functionality>
def test_config_creation():
    ...

# ❌ 错误
def creation_test():
    ...
```

### 4. 使用 pytest 标记

```python
@pytest.mark.skip(reason="需要真实的 API Key")
def test_real_api_call():
    ...

@pytest.mark.slow
def test_slow_operation():
    ...
```

### 5. 测试数据隔离

```python
# ✅ 正确：使用临时目录
def test_file_operations(self, tmp_path):
    test_file = tmp_path / "test.txt"
    ...

# ❌ 错误：使用固定路径
def test_file_operations(self):
    test_file = Path("/tmp/test.txt")  # 可能冲突
    ...
```
