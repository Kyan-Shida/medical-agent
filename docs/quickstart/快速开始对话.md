# 快速开始 - 与 AI 对话

## 方法一：使用对话脚本（推荐）

### 步骤 1：配置 API Key

编辑 `.env.dev` 文件，确保已设置正确的 API Key：

```bash
LLM_API_KEY=your_actual_api_key_here
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_MODEL=glm-4-flash
```

### 步骤 2：运行对话脚本

```bash
cd d:\traeFile\agent\medical
python chat.py
```

### 步骤 3：选择对话模式

**模式 1：简单对话**
- 每次对话独立，无历史记录
- 适合快速问答

**模式 2：多轮对话**
- 保留对话历史，上下文连贯
- 适合连续问诊
- 支持命令：
  - `history` - 查看对话历史
  - `clear` - 清空历史
  - `quit` / `exit` - 退出

## 方法二：使用 Python 交互式对话

```python
cd d:\traeFile\agent\medical
python
```

```python
from config.base_config import BaseConfig
from config.llm_config import LLMConfig
from core.llm.client import LLMClient

# 加载配置
config = BaseConfig(env_file=".env.dev")
llm_config = LLMConfig.from_env(config)

# 创建客户端
client = LLMClient(llm_config)

# 简单对话
response = client.simple_chat("你好，我感冒了怎么办？")
print(response)

# 多轮对话
messages = [
    {"role": "system", "content": "你是医疗助手"},
    {"role": "user", "content": "我发烧了"},
    {"role": "assistant", "content": "建议测量体温"},
    {"role": "user", "content": "38.5 度"}
]
response = client.chat(messages)
print(response.content)
```

## 对话示例

### 示例 1：感冒咨询

```
您：你好，我感冒了怎么办？
AI: 您好！感冒时建议您：
    1. 多休息，保证充足睡眠
    2. 多喝温水，保持身体水分
    3. 注意保暖，避免受凉
    4. 如果症状较轻，可以服用一些非处方的感冒药
    5. 如果发烧超过 38.5℃或症状持续加重，请及时就医
    
    请问您目前有哪些具体症状呢？
```

### 示例 2：儿童医疗咨询

```
您：孩子发烧了怎么办？
AI: 家长您好！孩子发烧时请保持冷静，以下是处理建议：
    
    【家庭护理】
    1. 测量体温，确认发烧程度
    2. 让孩子多休息，多喝水
    3. 适当减少衣物，保持室内通风
    4. 体温超过 38.5℃可考虑使用退烧药（对乙酰氨基酚或布洛芬）
    
    【需要立即就医的情况】
    - 3 个月以下婴儿发烧
    - 持续高烧不退（超过 39℃）
    - 出现抽搐、呼吸困难
    - 精神状态差、嗜睡
    
    请问孩子多大了？体温多少度？
```

### 示例 3：多轮连续问诊

```
您：我最近头痛
AI: 您好！头痛可能有多种原因。为了更好判断，请问：
    1. 头痛是什么部位？（前额/两侧/后脑/整个头部）
    2. 疼痛性质？（胀痛/刺痛/跳痛/压迫感）
    3. 持续多久了？
    4. 有没有其他伴随症状？（恶心/呕吐/发热等）
    
您：前额胀痛，有 2 天了，有点恶心
AI: 根据您的描述，前额胀痛伴恶心，可能的原因有：
    
    1. **紧张性头痛** - 常见，与压力、疲劳有关
    2. **鼻窦炎** - 前额部位疼痛，可能伴鼻塞
    3. **偏头痛** - 可能伴恶心、畏光
    
    建议：
    - 保证充足休息，避免过度用眼
    - 适当按摩太阳穴
    - 如果症状持续或加重，建议就医检查
    
    请问您最近是否压力大、睡眠不足？有鼻塞症状吗？
```

## 常用命令

| 命令 | 说明 |
|------|------|
| `quit` / `exit` | 退出对话 |
| `clear` | 清空对话历史（多轮模式） |
| `history` | 查看对话历史（多轮模式） |
| `Ctrl+C` | 中断当前对话 |

## 故障排查

### 问题 1：API Key 无效

```
❌ 错误：API Key 无效
```

**解决方案**：
1. 检查 `.env.dev` 文件中的 `LLM_API_KEY` 是否正确
2. 确保没有多余空格或引号
3. 确认 API Key 在智谱 AI 平台有效

### 问题 2：连接超时

```
❌ 错误：请求超时
```

**解决方案**：
1. 检查网络连接
2. 增加超时配置：`LLM_TIMEOUT=60`
3. 检查是否需要代理

### 问题 3：配置加载失败

```
❌ 错误：配置加载失败
```

**解决方案**：
1. 确认 `.env.dev` 文件存在于项目根目录
2. 检查文件格式是否正确
3. 重启终端或 IDE
