# Web 数据面板使用指南

## 📊 产品概述

**Web 数据面板**是一个专为产品经理设计的可视化数据监控工具，实时展示产品关键指标。

## 🚀 快速启动

### 方式 1：使用启动脚本（推荐）

```bash
cd medical
python web/run_metrics.py
```

### 方式 2：直接运行

```bash
cd medical
streamlit run web/metrics_dashboard.py --server.port 8502
```

### 访问地址

启动成功后访问：**http://localhost:8502**

## ✨ 功能特性

### 1. 今日概览

**展示内容**：
- 🤖 LLM 成功率
- 📚 RAG 命中率
- 🎯 意图准确率
- ⏱️ 平均响应时间

**状态标识**：
- 🟢 优秀（绿色）
- 🟡 良好（蓝色）
- 🔴 需改进（红色）

### 2. 详细指标

#### LLM 调用指标
- 总调用次数
- 成功/失败次数
- 总 Token 数
- 平均响应时间

#### RAG 检索指标
- 总检索次数
- 成功次数
- 平均结果数
- 平均响应时间

#### 意图识别指标
- 总识别次数
- 平均置信度
- 高置信度比例
- 意图分布

#### 用户指标
- 总会话数
- 独立用户数

### 3. 质量评估

**自动评分**：
- ✅ 优秀 - 达到目标值
- ⚠️ 良好 - 接近目标值
- ❌ 需改进 - 低于目标值

### 4. 趋势分析

**趋势图表**：
- LLM 成功率趋势（折线图）
- RAG 命中率趋势（折线图）
- 调用量趋势（多系列折线图）

**时间范围**：
- 可配置（1-30 天）
- 默认显示 7 天

## 📖 使用说明

### 侧边栏配置

**日期选择器**：
- 选择要查看的日期

- 范围：1-30 天
- 默认：7 天

**刷新按钮**：
- 点击刷新数据

## 🎯 产品经理日常工作流

### 早上（9:30）

**步骤**：
1. 打开浏览器访问 http://localhost:8502
2. 查看今日概览
3. 检查各指标状态
4. 如有异常（红色），记录并同步团队

**关注点**：
- LLM 成功率是否 < 95%
- RAG 命中率是否 < 85%
- 意图准确率是否 < 80%
- 响应时间是否 > 5 秒

### 周一（10:00）

**步骤**：
1. 调整趋势天数为 7 天
2. 查看周趋势
3. 分析指标变化
4. 输出周报

**分析内容**：
- 本周 vs 上周环比
- 趋势是上升还是下降
- 异常点分析

### 每月 1 号

**步骤**：
1. 调整趋势天数为 30 天
2. 查看月趋势
3. 月度复盘
4. 制定下月目标

## 📊 数据解读

### LLM 成功率

**优秀**：> 99%
**良好**：95-99%
**需改进**：< 95%

**可能原因**：
- API 服务商问题
- 网络问题
- 代码 bug

**改进行动**：
- 联系 API 服务商
- 优化重试机制
- 添加降级策略

### RAG 命中率

**优秀**：> 95%
**良好**：85-95%
**需改进**：< 85%

**可能原因**：
- 知识库不足
- 检索参数不合理
- 向量质量差

**改进行动**：
- 补充知识库文档
- 调整 top_k 参数
- 优化文本分割

### 意图准确率

**优秀**：> 90%
**良好**：80-90%
**需改进**：< 80%

**可能原因**：
- 分类器训练不足
- 意图定义不清晰
- 规则不完善

**改进行动**：
- 优化分类器
- 明确意图定义
- 完善规则

### 平均响应时间

**优秀**：< 3 秒
**良好**：3-5 秒
**需改进**：> 5 秒

**可能原因**：
- LLM 调用慢
- RAG 检索慢
- 网络延迟

**改进行动**：
- 使用更快的模型
- 优化向量检索
- 添加缓存

## 🔧 故障排查

### 问题 1：数据面板无法启动

**检查**：
```bash
# 检查端口是否被占用
netstat -ano | findstr :8502
```

**解决**：
```bash
# 更换端口
streamlit run web/metrics_dashboard.py --server.port 8503
```

### 问题 2：数据显示为 0

**原因**：还没有用户访问，没有数据积累

**解决**：
1. 先使用产品（聊天或 Web 面板）
2. 等待数据收集
3. 刷新页面

### 问题 3：趋势图不显示

**检查**：
- 数据文件是否存在：`data/metrics/`
- 数据格式是否正确

**解决**：
```bash
# 查看数据文件
cd data/metrics
ls
```
